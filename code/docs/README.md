# Устройство кода экспериментов

## Основные части

- `src/clusterization/` — реализация подготовки данных, кластеризации, метрик и выбора разбиения.
- `backend.py` — операции CPU/GPU. `metrics.py` — ARI и другие оценки. `selection.py` — сравниваемые правила выбора.
- `sampling.py` — разделение объектов и раскрытие меток, бутстрепные выборки.
- `light_series.py` — основные серии и контролируемые синтетические проверки.
- `scripts/` — запускаемые программы. `run_paper_experiments.py` объединяет воспроизведение экспериментов статьи.
- `configs/` — настройки NIP. `notebooks/` — интерактивный запуск.
- `fixtures/paper_inputs.zip` — компактные сохранённые входы для воспроизведения без загрузки моделей.
- `tests/` — проверки вычислений и протокола.

## Порядок работы

После подготовки признаков строится фиксированный набор разбиений. Метки раскрываются только для части объектов. Правила выбирают кандидата по частичному ARI, внутреннему индексу или их сочетанию. Скрытые метки используются после выбора для оценки ARI и потери качества.

`review_analysis.py` выполняет основную диагностику, `refine_review_analysis.py` — дополнительные проверки. Построение рисунков отделено от вычислений и выполняется `build_experiment_figures.py`. Результаты записываются в выбранный каталог отчётов и не включаются в Git.

Установка и команды запуска приведены в `code/README.md`.
