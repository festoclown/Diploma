# Первый GPU-пилот в Google Colab

Сценарий `configs/experiments/gpu_pilot.nip`: 300 синтетических объектов, KMeans/HDBSCAN/SpectralClustering, бюджеты 20 и 50, два повтора. Это техническая проверка, а не научный результат.

Следующий лёгкий сценарий — `configs/experiments/gpu_digits_light.nip`: 600 изображений цифр, бюджеты 20 и 50, пять повторов, случайная разметка и разметка с пропущенными классами. Его ячейка находится в конце ноутбука. Она создаёт отдельный отчёт с таблицами и PNG-графиками и скачивает ZIP с результатами. Сравнение `M6` с `M0` использует одинаковые повторы разметки; положительное значение `regret(M0) - regret(M6)` означает выигрыш `M6`. Пять повторов недостаточны для окончательного научного вывода.

Используйте [обновлённый ноутбук](colab_gpu_pilot.ipynb) и архив `clusterization-colab-pilot.zip` из корня проекта. Начните с новой среды Colab с GPU. Первая ячейка устанавливает проект, проверяет единственную CUDA-сборку cuML и выполняет импорты; затем запускайте только вторую ячейку.

**Причина предыдущей ошибки:** в среде одновременно оказались `cuml-cu12==26.2.0` и `cuml-cu13==26.6.0`. Файл `libcuml.so` есть только в пакете cu13. [Скрипт `rapidsai-csp-utils/colab/pip-install.py`](https://github.com/rapidsai-community/rapidsai-csp-utils/blob/main/colab/pip-install.py) по умолчанию устанавливает RAPIDS 26.02 для cu12; в этом сценарии его больше не вызываем. Для pip-пакетов [NVIDIA требует сборку, соответствующую установленному CUDA toolkit](https://docs.nvidia.com/datascience/install/). Если свежая среда использует другую версию CUDA, проверьте её прежде чем менять семейство пакетов.

При `ImportError` сохраните вывод ячейки и `nvidia-smi`. `mean_regret`: меньше лучше; `mean_ari`: больше лучше. Два повтора недостаточны для научного вывода.

Строковые элементы списков NIP должны быть в кавычках: например, `methods: ['M0', 'M1']`. В исправленной версии конфигов это соблюдено. Если работаете с архивом, загруженным до исправления, замените его обновлённым архивом или поправьте конфиги прямо в Colab. Ячейка запуска теперь выводит полный текст ошибки дочернего скрипта.
