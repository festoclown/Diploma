# Исходные массивы для экспериментов статьи

paper_inputs.zip содержит фиксированные признаки и векторные представления шести подвыборок, метки, ID, манифесты источников, шесть исходных таблиц решений для сверки и предварительные запуски. Размер около 3 МБ. input_manifest.json задаёт SHA256 каждого файла.

Пакет взят из сохранённых авторских запусков, использованных в статье. Он позволяет повторно строить разбиения и пересчитывать все правила без загрузки модели и корпусов. Скрипты скачивания, подготовки данных и кодирования текстов находятся в scripts/. Для полного нового запуска из исходных корпусов используйте основной ноутбук и текстовые зависимости проекта.
