# Артефакты и интерпретация результатов

## Сохраняемые файлы

| Путь | Содержание |
|---|---|
| data/raw/CORPUS/records.jsonl | id, group, text, label; официальные части объединены |
| data/raw/CORPUS/manifest.json | Источник, разрешённая revision при наличии, контрольная сумма, размер |
| models/HASH/snapshot/ | Локальные файлы эмбеддера |
| models/HASH/manifest.json | Repo, requested/resolved revision, SHA256 каждого файла |
| data/processed/DATASET/labels.npz | Массивы y, groups, ids в одном фиксированном порядке |
| data/processed/DATASET/documents.jsonl | Очищенные тексты и ID, без меток |
| data/processed/DATASET/vectors.npz | Синтетический или табличный массив x |
| data/processed/DATASET/embedding-HASH/ | Текстовый массив x и manifest с долей обрезки |
| artifacts/pools/DATASET/HASH/pool.npz | labels размера M×n: по одной строке на кандидата |
| artifacts/pools/DATASET/HASH/manifest.json | Порядок ID, алгоритмы/параметры, внутренние оценки, coverage, пропущенные кандидаты и контрольная сумма |
| artifacts/frozen_mixture.json и frozen_mixture_cuda.json | Раздельные веса M4 для CPU и CUDA, development-критерий, результаты сетки, контракт параметров |
| results/NAME/DATASET/HASH/manifest.json | Полный конфиг, источники, среда, статус, хеши результатов |
| .../split.npz | Индексы reserve и test относительно подготовленного набора |
| .../draws/SCENARIO-rNNN-mBUDGET.npz | Индексы L, partial_ari[M], bootstrap_ari[B,M] |
| .../selections.jsonl | Одна строка на метод и условие получения разметки |
| .../diagnostics.jsonl | Одна строка на кандидата и условие, включая полную резервную оценку |
| .../skipped.jsonl | Невыполнимые условия с причиной; пустой файл при отсутствии пропусков |

NPZ читается с `allow_pickle=False`; массивы состоят из чисел и строк. Индексы объектов всегда относятся к порядку подготовленного датасета, а не к исходному CSV. Нельзя соединять внешние метки по позиции, не сверив ID.

## Основные поля selections.jsonl

| Поле | Как читать |
|---|---|
| dataset/cell/kind | Уникальная реализация, геометрическая ячейка/набор, synthetic/tabular/text |
| scenario/budget/repeat | Условие получения разметки; методы внутри него парные |
| selected_id/selected_k/selected_coverage/selected_aliases | Выбранное разбиение, доля назначенных точек и все алгоритмы, давшие такой же результат |
| test_ari/test_ami | Проверочное внешнее качество |
| oracle_ari | Лучший ARI среди всех кандидатов на том же T |
| regret | oracle_ari − test_ari; меньше лучше |
| near_optimal/large_loss | Индикаторы заданных в конфиге порогов |
| external_leader | Индекс внешнего лидера по L в порядке manifest пула |
| eligible_count | Размер допустимого множества M2/M5/M6; для других правил null |
| leader_changed | Выбран ли кандидат, отличный от внешнего лидера |
| selected_gap | Потеря частичного ARI относительно лидера |
| selected_bootstrap_sd | SD парной разности выбранного кандидата с лидером для M6 |
| coverage | Доля представленных истинных классов; только диагностика |
| positive_pairs | Число пар объектов L с одинаковой истинной меткой |
| labelled_groups | Число независимых групп, представленных в L |
| bootstrap_degenerate_fraction | Доля bootstrap-выборок без двух классов либо без положительных пар |
| no_information | Флаг такой вырожденности на исходном L |
| fallback_used | Был ли реально применён переход к M0 |
| missing_classes_ari | Качество на T для классов, отсутствовавших в L; null, если оценка неприменима |

Null не означает нулевое качество. Например, ARI на отсутствующих классах не рассчитывается, если там нет хотя бы двух классов. Сравнивать такую колонку нужно вместе с числом пригодных наблюдений и `missing_test_n`.

## Отчёт

- `selections.csv`: плоские наблюдения; поля с несколькими aliases представлены строкой, исходный структурированный вариант остаётся в JSONL.
- `per_dataset.csv`: средние и медианные потери, качество, частота крупных ошибок и размер допустимого множества для каждой реализации.
- `paired_contrasts.csv`: M6 против нескольких baseline на совпавших repeat; **положительный mean_gain_M6 означает пользу M6**. Percentile-интервал строится по 2000 повторным выборкам парных разностей.
- `synthetic_contrasts.csv`: сначала усреднение повторов внутри реализации, затем интервал по реализациям одной геометрической ячейки. `n_realizations=1` даёт вырожденный интервал и не доказывает точность.
- `text_macro_descriptive.csv`: равновесное макросреднее корпусов внутри каждой серии; описательная сводка, без утверждения универсального переноса.
- `regret-*.png`: средний regret по бюджетам; отдельные графики для корпуса/ячейки, сценария и варианта настроек. На этих линиях нет интервалов; интервалы находятся в таблицах.
- `manifest.json`: конфиги и подписи источников отчёта, число строк и описание процедуры интервалов.

Не объединяйте development с confirmation в один отчёт. Генератор отчётов пропускает development, останавливается при незавершённых запусках и обнаруживает дубли наблюдений. Поле `series` разделяет разные параметры, чтобы случайно не усреднить c=0.5 и c=2 как один метод.

## Аудит

Манифесты сохраняют версии Python, библиотек и SHA256 исходных Python-модулей. Полностью развёрнутый конфиг сохраняется для каждого запуска; исходная версия NIP-файла может дополнительно храниться в системе контроля версий пользователя.

Хеши защищают от случайной подмены/перестановки файлов и устаревшего кеша, но не заменяют контроль научного протокола. При изменении реализации или версий библиотек делайте новую копию проекта с отдельными артефактами. Старый кеш не обязан автоматически пересчитываться от любого изменения кода. Сохранённая среда и хеши позволяют установить, каким кодом он был получен.
