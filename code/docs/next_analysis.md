# Диагностика переключений и следующая серия

Рабочий план после согласования Q1 и Q2. Цель — установить условия пользы и вреда внутреннего индекса. Текущие пилоты являются материалом разработки, а не независимым подтверждением будущего правила.

## Этап 1. Единая таблица решений

Вход: сохранённые selections.jsonl, diagnostics.jsonl, draws/*.npz, split.npz, pool.npz и векторы из того же запуска. Ключ строки: набор, пул, split, схема меток, бюджет, повтор, метод. Сопоставлять методы только по полностью совпадающим условиям.

Для M1 и M6 извлечь ID лидера и выбранного кандидата, алгоритм и число кластеров, частичный ARI, проверочный ARI, внутреннюю оценку, отставание, SD парной разности, размер допустимого множества. Добавить истинное покрытие исключительно для последующей диагностики. Проверить причины исключения кандидатов и обработки шума. Совпадение ARI не считать совпадением разбиений.

## Этап 2. Простые сравнения

На одних метках и пуле сравнить M0 (внутренний максимум), M1 (внешний максимум), M2 (внутреннее разрешение равенств), M3 (фиксированная смесь), M5 (фиксированный допуск), M6 (адаптивный допуск), M7 (частота бутстрепных побед). M4 требует отдельной настроечной серии. Не подбирать пороги по результатам будущей подтверждающей серии.

Для M6 диагностировать отдельно: лучший проверочный кандидат исключён допуском; хороший кандидат допущен, но внутренний индекс предпочёл худший; переключения не произошло. Это диагностика по скрытым меткам после выбора, не доступная самому правилу.

## Этап 3. Результаты и графики

1. Парный график проверочного ARI M1→M6 по каждому повтору.
2. Частота переключений и доли выигрыша, равенства ARI и проигрыша среди переключений; везде указать знаменатель.
3. Диаграмма отставание–SD с линией допуска; цвет — проверочная разница относительно лидера.
4. Потери всех методов по бюджетам и схемам раскрытия меток.
5. Для Digits сопоставить ID решений silhouette и Davies–Bouldin, не только ARI.
6. Для Breast Cancer разобрать каждое ухудшение и предпочтения индекса по числу кластеров.

При пяти повторах показать все наблюдения; не делать выводов о статистической значимости по одному среднему.

## Этап 4. Вычислительная устойчивость

Зафиксировать пул и метки. Пересчитать бутстреп при B=30, 200, 500 с несколькими seed; сравнить SD, допустимые множества и выбранные ID. Это проверка случайности вычисления допуска, не новые независимые данные. Предварительно проверить совпадение пересчитанных исходных решений с архивом.

## Этап 5. Расширение

После диагностики заморозить правила. На синтетике независимо менять соответствие геометрии классам, дисбаланс, покрытие при фиксированном бюджете и состав пула. Использовать несколько независимых реализаций каждого условия. На реальных данных начать с Digits, Breast Cancer и Dry Bean. Рабочие ориентиры: 30–50 повторов разметки, B=200, бюджеты 20/50/100/200 при допустимом размере резерва. Текстовый домен — дополнительная проверка переноса после числовых данных.

Обобщение оценивать по задачам, а вариативность разметки — внутри задач. Основные показатели: средняя потеря, вероятность ухудшения, величина отрицательных эффектов, частота и последствия переключений. Отрицательный результат для M6 допустим и научно содержателен.
